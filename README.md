# VibeCheck

**VibeCheck** is a minimalist, responsive web application designed to give users an instant mental boost. Whether you need a heartfelt compliment or a quick laugh, VibeCheck delivers high-quality "good vibes" at the click of a button.

**Live Demo:** [https://yinjuchen.github.io/vibecheck/](https://yinjuchen.github.io/vibecheck/)

## ✨ Features

* **Dual Modes:** Seamlessly toggle between "Compliments" for positive affirmations and "Jokes" for a quick laugh.
* **Glassmorphism UI:** A modern, frosted-glass aesthetic with soft animated background gradients that adapt to the viewport.
* **Micro-interactions:** Includes a tactile 3D button effect and dynamic "sparkle" particle bursts upon generation for satisfying user feedback.
* **Mobile-First Design:** Fully responsive layout that scales beautifully from high-resolution desktop monitors to mobile devices.
* **Accessibility Optimized:** Uses semantic HTML and ARIA attributes to ensure a friendly experience for screen readers and keyboard navigation.

## 🚀 Tech Stack

* **HTML5:** Structured with semantic elements for SEO and accessibility.
* **CSS3:** Custom properties (variables), Flexbox, and CSS Animations for the "living" background and 3D effects.
* **JavaScript (ES6+):** Clean, vanilla JS logic for state management and DOM manipulation—built with a "no-frameworks-needed" philosophy.

## 🛠️ Installation & Usage

Since this is a front-end project, no complex installation is required.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/yinjuchen/vibecheck.git](https://github.com/yinjuchen/vibecheck.git)
    ```
2.  **Open the project:**
    Simply open `index.html` in your favorite web browser or use a local server like Live Server in VS Code.

## 🎨 Design Philosophy

The goal was to create an interface that felt "light" and "airy." By using `backdrop-filter: blur()`, we achieved a premium glass look that allows the animated background blobs to peek through, creating a sense of organic movement without distracting the user from the content.

## 📈 Future Roadmap
